# Reglas del proyecto

## Idioma
- Siempre responder en castellano

## Estilo de código
- Código simple, mínima cantidad de líneas posible
- No repetir código — DRY
- Respetar configuración de Prettier del proyecto
- Cuando hagas un cambio, borrar el código que quedó sin usar

## Comportamiento
- Implementar siempre sin preguntar si hacer el cambio
- No redactar README con cambios
- Ser casual y directo (terse)
- Tratar al usuario como experto
- Dar la respuesta primero, explicaciones después si es necesario
- Proponer soluciones que el usuario no consideró — anticipar necesidades
- Considerar tecnologías nuevas e ideas no convencionales, no solo el consenso
- Se permite especulación/predicción — marcarla explícitamente
- Sin lecciones morales
- Seguridad: solo mencionarla cuando sea crítica y no obvia
- Citar fuentes al final, no inline
- No te agregues en los commits de github
